## Usage

This component takes a standard image source and renders it onto a WebGL plane using \`@react-three/fiber\`. It uses an intersection observer to trigger a custom simplex-noise fragment shader when the image scrolls into view.

```tsx
import { DiffusionImageReveal } from "@/components/creative/diffusion-image-reveal";

export function HeroSection() {
  return (
    <div className="w-full">
      <DiffusionImageReveal 
        src="https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?auto=format&fit=crop" 
        className="w-full max-w-lg mx-auto"
      />
    </div>
  );
}
```
