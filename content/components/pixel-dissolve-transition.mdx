## How It Works

This component generates an absolute-positioned CSS Grid overlay matching the dimensions of the screen. Inside the grid, we render an array of square `<motion.div>` "pixels".

When triggered, we animate the scale and opacity of these pixels. By pre-calculating a randomized array of stagger delays (`Math.random()`), each block animates at a slightly different time. 

Once the blocks have fully covered the screen (creating a solid color), we instantly swap the underlying page content, and then the blocks reverse their animation to scatter away.
