## How It Works

This component uses Framer Motion's `useScroll` to track the user's vertical scroll progress within the container. 
It then maps that progress `[0, 1]` to the `pathLength` style property of the SVG `<motion.path>`.

We pass the `scrollYProgress` value through a `useSpring` hook to give the drawing animation a smooth, fluid feeling instead of rigidly locking to the exact scroll pixel.
