## How It Works
Rendering 3D scenes is normally reserved for WebGL/Canvas, but we can achieve stunning pseudo-3D effects using SVG by applying an isometric projection matrix algorithm to standard X/Y Cartesian coordinates. The `SvgIsometricGrid` mathematically calculates a grid of dots in isometric space `(isoX, isoY)`. When a dot is clicked, it records that coordinate as an epicenter, and every other dot calculates its Pythagorean distance from that epicenter to mathematically stagger a Framer Motion `delay`, causing a perfectly smooth, physical ripple effect across the terrain.
