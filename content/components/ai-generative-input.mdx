## Installation

```bash
npx kinetic-ui-cli@latest add ai-generative-input
```

## How It Works
The `AIGenerativeInput` component wraps a standard `<textarea>` in a `framer-motion` layout container to smoothly handle auto-expanding heights. When submitted, it renders an absolute-positioned animated gradient border to simulate "thinking", and utilizes `canvas-confetti` to trigger a subtle micro-interaction explosion at the exact coordinates of the submit button.
