## Usage & Integration

The **Reasoning Tree** component uses a recursive `TreeNode` sub-component to render infinitely nestable levels of thought processes. 

It pairs beautifully with LLM architectures that emit structured logging (like LangChain callbacks or Vercel AI SDK `onToolCall` streams). The collapsible nature is powered by `framer-motion`'s `AnimatePresence` applying height transitions.
