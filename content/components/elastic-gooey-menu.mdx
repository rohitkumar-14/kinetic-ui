```bash
npx kinetic-ui-cli@latest add elastic-gooey-menu
```

## How It Works
The `ElasticGooeyMenu` utilizes an advanced technique where a standard HTML `<div>` is combined with an SVG `<path>` acting as its leading edge. Using `framer-motion`, we animate the SVG's `d` attribute from a deeply curved bezier curve (`Q` command) into a straight vertical line as the menu slides into view. This creates the optical illusion that the menu is made of stretching rubber.
