## How It Works
Usually, soft-body physics requires heavy WebGL libraries like `matter.js` or `three.js`. This component achieves a gelatinous, soft-body effect natively using purely SVG paths and `framer-motion`. By mapping the drag values (`x` and `y`) into a `useTransform` hook, we mathematically deform the Bezier curve control points (`C`) of a circle on the fly, creating a 0-dependency, high-performance physical reaction.
