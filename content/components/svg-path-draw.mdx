## How It Works
The `SvgPathDraw` component leverages `framer-motion`'s ability to natively animate SVG attributes. Specifically, it manipulates the `stroke-dasharray` and `stroke-dashoffset` CSS properties behind the scenes via the `pathLength` motion value. We wrap the container in a `useInView` hook with a negative margin so that the drawing animation triggers precisely when the component enters the user's viewport, making it perfect for hero sections or storytelling graphics.
