## Mechanics

This component merges continuous trigonometric animation with reactive physics:

1. **Orbit Paths**: A global `requestAnimationFrame` loop increments a `time` variable. Each planetary node calculates its Cartesian `(x, y)` position relative to the center using `Math.cos()` and `Math.sin()`.
2. **Hover Pause**: When any node (or the center avatar) is hovered, the global time loop halts, pausing the orbit so the user can comfortably click the target.
3. **Magnetic Core**: The center avatar maps its translation to `cursorX` and `cursorY` via `useSpring`, creating a subtle parallax pull effect as you move your mouse across the container.
