## Installation

```bash
npx kinetic-ui-cli@latest add infinite-marquee
```

## How It Works
The `InfiniteMarquee` uses pure CSS keyframe animations instead of JavaScript intervals for maximum performance and buttery-smooth scrolling (no jitter). It duplicates your children internally so the loop appears completely seamless. You can pause the animation on hover, change the speed, and reverse the direction.
