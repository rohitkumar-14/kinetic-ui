## How It Works
Morphing SVGs is notoriously tricky because you usually have to interpolate between two drastically different mathematical paths. The `SvgShapeMorph` component utilizes `framer-motion`'s native SVG path interpolation. By ensuring that `pathA` and `pathB` possess the exact same structure (the same number of `M` and `L` plotting commands), Framer Motion is able to Tween between the point coordinates flawlessly, allowing a "Play" icon to organically reshape into a "Pause" icon.
