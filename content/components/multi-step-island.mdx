## How It Works
Traditional web design uses standard "Popup Dialogs" which abruptly appear in the center of the screen. The `MultiStepIsland` bypasses this by utilizing `framer-motion`'s powerful `layoutId` prop. When the user clicks the pill button, React unmounts the button and mounts the large modal container, but because they share the same `layoutId="island-container"`, Framer Motion intercepts the DOM change and automatically calculates a flawless FLIP (First, Last, Invert, Play) animation to physically stretch and morph the button into the modal.
