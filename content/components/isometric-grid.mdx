## How It Works

This component relies on CSS 3D transforms (`perspective` and `transform-style: preserve-3d`) combined with Framer Motion. 
We track the mouse position relative to the container and map those X/Y coordinates to the grid's `rotateX` and `rotateZ` values using `useTransform`.

Each individual card inside the grid then utilizes simple CSS hover states to lift upwards (`-translate-y`) and cast a larger drop shadow, enhancing the 3D depth effect.
