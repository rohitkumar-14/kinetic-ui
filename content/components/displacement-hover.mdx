## Installation

```bash
npx kinetic-ui-cli@latest add displacement-hover
```

## How It Works
Instead of using heavy canvas or Three.js dependencies, the `DisplacementHover` component uses a powerful SVG `<feDisplacementMap>` coupled with `<feTurbulence>`. By animating the `scale` property of the displacement map via React state, it creates a true physics-based liquid distortion effect that seamlessly morphs between two images.
