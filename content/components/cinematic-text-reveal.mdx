## Installation

```bash
npx kinetic-ui-cli@latest add cinematic-text-reveal
```

## How It Works
The `CinematicTextReveal` component automatically splits any string into words, and words into individual characters. When the component scrolls into view (`useInView`), it fires a staggered `framer-motion` sequence. Each character animates from an offset `rotateX` and `rotateY` angle in 3D space, dropping in with a satisfying spring bounce to create a highly polished, cinematic introduction.
