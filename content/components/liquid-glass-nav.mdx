
## How It Works
The `LiquidGlassNav` utilizes an advanced SVG `<filter>` layer (`feGaussianBlur` + `feColorMatrix`) applied directly over a `framer-motion` layout projection. When the active state changes, the layout projection mathematically calculates the distance between the elements, and the SVG filter merges the pixels to create a true physics-based liquid morphing effect.
