```bash
npx kinetic-ui-cli@latest add generative-ai-shimmer
```

## How It Works
The `GenerativeAiShimmer` component splits text into words and applies a heavily staggered `framer-motion` animation. The secret to the "materialization" effect is animating the CSS `filter` property from a massive `blur(20px)` down to `0px`, combined with a subtle scale-down and a custom bouncy easing curve. This perfectly simulates the aesthetic of a generative AI engine writing text in real-time.
