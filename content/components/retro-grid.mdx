
## How It Works
The `RetroGrid` component uses pure CSS backgrounds (linear gradients) and 3D transforms (`rotateX` with `perspective`) to create an infinitely panning 3D floor grid. It is highly performant because it relies solely on CSS hardware-accelerated animations rather than canvas or WebGL.
