## Usage

This component utilizes CSS `clip-path: polygon(...)` tied to an interactive slider handle mapped from 0% to 100%.

It is extremely useful for A/B testing AI models, visualizing RAG (Retrieval-Augmented Generation) improvements, or showing prompt engineering "before/after" results. Pass arbitrary React node children to `modelA_Content` and `modelB_Content` to compare anything from raw text to complete UI widgets.
