## Installation

```bash
npx kinetic-ui-cli@latest add before-after-slider
```

## How It Works
The `BeforeAfterSlider` relies on a pure CSS `clip-path: inset(...)` to perfectly mask the foreground image. State tracking for mouse and touch events dynamically updates the position of the clip-path mask and the slider handle in real time without lag.
