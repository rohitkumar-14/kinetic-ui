
## How It Works
The `VisionGlassDock` uses `framer-motion`'s `useMotionValue` to track the mouse's X coordinate across the entire dock container. For each individual icon, a `useTransform` hook calculates its exact distance to the mouse cursor. Based on this distance, the width and height of the icon are smoothly interpolated, creating that iconic magnification effect without any jitter.
