
## How It Works
The `SvgFlashlightMask` allows you to stack two completely different React layouts on top of one another. The top layout (the `revealChildren`) is completely clipped out of existence using the `maskImage` CSS property. By feeding the X and Y coordinates of your cursor from `framer-motion` into a `radial-gradient` mask via CSS custom variables (`--x` and `--y`), it creates a "hole" in the clipping mask, causing the top layer to peek through precisely where your mouse is pointing, acting like a flashlight in the dark.
