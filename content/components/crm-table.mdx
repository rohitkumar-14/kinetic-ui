## Features

- **Pipeline Stages**: Visual colored badges for New Lead, Contacted, Qualified, Proposal, Won, and Churned.
- **Search & Filter**: Real-time filtering by company name, contact name, or email.
- **Deal Value Formatting**: Formatted USD deal values with monospace numerical alignment.
- **Bulk Actions**: Row selection checkboxes with delete and export controls.
- **Responsive**: Smooth horizontal scrolling with sticky-ready action column.
