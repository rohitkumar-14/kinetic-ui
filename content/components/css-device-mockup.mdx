
## How It Works
Traditionally, high-fidelity 3D device mockups require heavy libraries like `three.js`. The `CssDeviceMockup` component bypasses this by stacking layers of CSS `div`s with `translate-z` offsets and `preserve-3d` wrappers. It dynamically tracks the mouse pointer to rotate the entire chassis using `framer-motion` springs. Best of all, because it's just CSS, you can pass standard React children directly into the screen container and they remain fully interactive!
