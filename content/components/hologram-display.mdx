## Installation

```bash
npm install @react-three/fiber @react-three/drei three
npx kinetic-ui-cli@latest add hologram-display
```

## How It Works
The `HologramDisplay` uses `@react-three/fiber` to render the metallic projector base and an open cylinder with `AdditiveBlending` for the volumetric light cone. The `<Html>` component from `@react-three/drei` is used to perfectly place standard DOM elements inside the 3D projection, complete with CSS filters to simulate the glowing holographic scanlines.
