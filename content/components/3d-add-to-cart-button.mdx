## Usage

This button elevates standard e-commerce interactions. When clicked, it uses \`framer-motion\` to physically throw a representation of the product directly into the user's cart at the top right of the screen.

```tsx
import { ThreeDAddToCartButton } from "@/components/creative/3d-add-to-cart-button";

export function ProductPage() {
  const handleAdd = () => {
    // Fire your cart state update
    console.log("Item added!");
  };

  return (
    <div className="w-full flex justify-center py-10">
      <ThreeDAddToCartButton onClick={handleAdd} productColor="#3b82f6" />
    </div>
  );
}
```
