## Usage

This chart uses \`@react-three/fiber\` and \`@react-three/drei\` to draw a 3D line in space, providing a highly immersive alternative to standard 2D SVG charts.

```tsx
import { WebGLLineChart } from "@/components/creative/webgl-line-chart";

export function Dashboard() {
  const data = [10, 20, 15, 30, 25, 40, 50, 45, 60];

  return (
    <div className="w-full">
      <WebGLLineChart data={data} color="#10b981" />
    </div>
  );
}
```
