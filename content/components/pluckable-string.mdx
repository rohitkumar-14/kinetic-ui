## How It Works
The `PluckableString` is an incredibly satisfying micro-interaction. It uses `framer-motion` to track the relative Y coordinate of your mouse as it drags across a container. We map this Y coordinate directly into the control point of an SVG Quadratic Bezier Curve (`Q`). When the mouse leaves the container, the Y coordinate is snapped back to the center using a spring configuration with extremely low `damping`, causing the control point to rapidly oscillate and simulate a vibrating string.
